Simple to do app in vanilla JS. No backend, tasks are stored in a JSON file which has to be
downloaded. Temporal changes and info is stored in the browser's local storage.

The objectives of this app were to play around with different CSS styles and to practice
storing data in the browser (local storage, cookies or session) without a server.
