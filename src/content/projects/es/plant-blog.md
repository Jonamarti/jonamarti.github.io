Aplicación full stack. Usa MongoDB cloud para la base de datos, NodeJS y Express en el
backend, y React en el frontend.

Cada planta tiene un rango de condiciones atmosféricas en el que sobrevive, como temperatura
y humedad. A veces cae una granizada o llega una ola de calor y nuestras plantas se resienten
o mueren. La mitad de la aplicación está dedicada a avisar al usuario cuando se prevén esas
condiciones extremas en los próximos días. Para ello se apoya en la parte de blog, donde el
usuario sube el progreso de cada planta junto con la información de la especie, y esos datos
se cruzan con una API meteorológica.
